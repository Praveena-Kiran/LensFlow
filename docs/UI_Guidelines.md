# LensFlow UI Guidelines

Version: 1.0

Status: In Progress

---

# Design Philosophy

LensFlow should feel like a premium desktop application.

Users should immediately understand what to do.

The interface should feel calm, elegant and spacious.

Every screen should contain one obvious primary action.

Avoid visual clutter.

Avoid technical information.

Avoid unnecessary controls.

Technology should disappear into the background.

# Shadows

Very soft.

Large blur.

Low opacity.

Never use harsh shadows.

# Glass Effect

Subtle transparency.

Minimal blur.

Soft border.

Modern.

# Navigation

Minimal Sidebar.
