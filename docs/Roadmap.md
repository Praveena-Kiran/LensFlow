# Wield Roadmap

## Done in 1.0

- Camera feed and MediaPipe hand tracking
- Built-in gestures, plus custom poses users record themselves
- Motions: built-in swipes and recorded movements (DTW)
- Studios with events: apps, files, websites, hotkeys, PowerPoint, flows
- Gesture control in every studio, and a live gesture tester
- Accessibility settings: sensitivity, hold to trigger, activation gesture
- Routine learning with suggestions, notifications and a scheduler
- Themes (Dark, Light, Jungle, Galaxy), first-run welcome, foggy window
- Windows app built and self-tested by GitHub Actions; project website

## Next

- Code signing, so Windows doesn't warn on first run
- An installer (Start menu shortcut, uninstaller)
- Two-hand gestures and more built-in motions
- Per-studio sensitivity settings
- Optional voice feedback for confirmations
