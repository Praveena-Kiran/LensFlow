# LensFlow Screen Specifications

Version: 1.0

Status: In Progress

---

# 1. Welcome / Onboarding

Purpose

Introduce LensFlow and guide first-time users.

Primary User Goal

Understand what LensFlow does and enter the application.

Components

- LensFlow Logo
- Welcome Text
- Illustration
- Get Started Button
- Theme Selection (optional)

Primary Action

Get Started

Should NOT Show

- Sidebar
- Settings
- Technical information
- Camera feed

---

# 2. Home

Purpose

The central dashboard where users access and manage their Studios.

Primary User Goal

Launch or create a Studio.

Components

- Sidebar
- Search Bar
- Studio Cards
- Create Studio Button

Primary Action

Create New Studio

Secondary Actions

Open Studio

Search Studios

Should NOT Show

- Camera preview
- Gesture confidence
- FPS
- Debug logs
- Technical settings

---

# 3. Studio

Purpose

Display everything inside one Studio.

Primary User Goal

Launch a complete workspace.

Components

- Sidebar
- Studio Header
- Application Cards
- Workflow Cards
- Launch Studio Button

Primary Action

Launch Studio

Secondary Actions

Edit Studio

Duplicate

Delete

Should NOT Show

- Developer information
- Backend logs
- Raw configuration files

---

# 4. Create Studio

Purpose

Allow users to build a brand-new Studio.

Primary User Goal

Create a personalized workspace.

Components

- Studio Name
- Description
- Icon Picker
- Accent Color Picker
- Create Button

Primary Action

Create Studio

Should NOT Show

- Advanced settings
- Developer options

---

# 5. Customize Studio

Purpose

Modify an existing Studio.

Primary User Goal

Personalize the Studio.

Components

- Studio Information
- Applications List
- Websites List
- Workflow List
- Gesture Assignment
- Theme Selection

Primary Action

Save Changes

Secondary Actions

Cancel

Reset

---

# 6. History

Purpose

Show previously launched Studios and workflows.

Primary User Goal

Review recent activity.

Components

- History Timeline
- Search
- Filters

Primary Action

Open Previous Studio

Secondary Action

Clear History

---

# 7. Settings

Purpose

Manage global LensFlow preferences.

Primary User Goal

Customize the application.

Components

- Theme
- Startup Options
- Notifications
- Camera Settings
- Gesture Sensitivity
- About LensFlow

Primary Action

Save Settings

Should NOT Show

- Raw MediaPipe values
- Technical debugging information

---

# Global UX Rules

Every page must:

• Have one obvious primary action.

• Use reusable components only.

• Feel calm and uncluttered.

• Maintain generous spacing.

• Avoid technical language.

• Never overwhelm the user.

The interface should always make users feel:

- Organized
- Productive
- Calm
- In Control
