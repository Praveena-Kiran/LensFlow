# Known Issues

- Windows SmartScreen warns on first run because the app isn't code-signed yet
  (More info → Run anyway).
- Recognition depends on lighting: a dim or strongly backlit room makes hands
  harder to track.
- Large tilts of the hand (over about 20°) can stop a recorded pose from
  matching. Recording takes at slightly different angles helps.
- Themes apply after a restart (Settings offers "Restart now").
- PowerPoint control and start-at-sign-in are Windows only.
